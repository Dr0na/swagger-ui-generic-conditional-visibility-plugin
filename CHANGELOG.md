# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-05-28

### Added

- Generic Swagger UI plugin (`SwaggerUIGenericConditionalVisibilityPlugin`) driven by OpenAPI extensions (`x-conditional`, `x-conditional-enum-map`, `x-conditional-schema-map`, `x-conditional-example-map`, `x-visibility`).
- Cascading path / query / header selectors with request-body gating and resolved schema/example.
- Static demos (`demo/catalog`, `demo/deployments`) and documentation with screenshots.
- Spring Boot auto-configuration starter (`spring-boot-starter/`).
- GitHub Actions CI and release workflows.
